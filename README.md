# 📱 Lost IT? Found It!

## Project Description
Lost IT? Found It! is designed to help students at the University of Texas at Arlington (UTA) quickly locate their lost items. The app serves as a common platform for users to report and search for lost and found items, significantly reducing the time and stress associated with these situations. Key features include:

- **User Account Management:** Users can create accounts, log in, and log out. The app also provides an option to reset passwords and delete accounts. 🔒
- **Lost Item Reporting:** Users can report lost items by creating a post that includes a description and photos. 🕵️‍♂️
- **Found Item Reporting:** Users can also report items they have found, making it easier for those who have lost items to recover them. 🛍️
- **Claim Functionality:** When a user finds a match for their lost item, they can claim it directly through the app. ✔️
- **Chat Feature:** Users can communicate with the authors of posts through an integrated chat feature, facilitating discussions about lost items. 💬
- **Notifications:** Users receive notifications about updates related to their lost items. 🔔
- **Location Services:** The app allows users to add the location of lost and found items using a map feature, enhancing the chances of recovery. 🗺️

## Overall Design Approach
The development of Lost IT? Found It! adhered to software engineering principles and best practices. The design approach involved multiple stages:

1. **Requirements Gathering:** We identified the key functionalities that the app should support based on user needs.
2. **Use Case Development:** We created high-level use cases that represent the interactions between users and the system.
3. **Design Patterns:** We applied appropriate design patterns to ensure a robust architecture.
4. **Modeling:** We developed a domain model, sequence diagrams, and class diagrams to visualize the system's components and their interactions.
5. **Implementation:** The app was built following the design specifications and guidelines.
6. **Testing and Iteration:** The app was tested thoroughly, and user feedback was incorporated into subsequent iterations.

## Requirements
The Lost IT? Found It! app has several functional requirements that dictate its core functionalities. These include:

- User account creation and management (login, logout, password reset, account deletion). 🧑‍💻
- The ability to report lost and found items. 🗒️
- A dashboard for users to view and manage their reported items. 📊
- Chat functionality to communicate with other users. 🤝
- Notifications for updates on reported items. 📬
- A map feature to assist users in locating lost items. 🧭

## Use Cases
The key use cases for the app include:

- **Create Account:** Users can sign up and create a personal account to access app features. ✍️
- **Login/Logout:** Registered users can log into their accounts and log out when finished. 🔑
- **Report Lost Item:** Users can create a post to report an item they have lost. 📣
- **Claim Found Item:** Users can claim an item that matches their lost item report. 🏷️
- **View Lost Items List:** Users can view a list of all reported lost items. 📋
- **Comment on Posts:** Users can leave comments on posts regarding lost items. 💭
- **Chat with Users:** Users can engage in direct communication with other users through chat. 📲
- **Admin Functions:** Administrators can manage user posts and remove inappropriate reports. 🛠️

## Design Diagrams
- **Domain Model:** Visual representation of the key entities in the system and their relationships. 📐
- **Sequence Diagrams:** Illustrate how different parts of the app interact over time during specific use cases. ⏳
- **Class Diagrams:** Outline the classes in the application, their attributes, and methods. 🏗️

## Android Application Preview
The app features an intuitive user interface designed for easy navigation. Key screens include:

- **Login Screen:** Allows users to enter their credentials and access their accounts. 🖥️
- **Dashboard:** Displays all reported lost and found items along with options to report new items or claim found items. 📺
- **Item Reporting:** A user-friendly form for entering details and uploading photos of lost or found items. 📸
- **Chat Interface:** Provides a simple messaging interface for users to communicate. 💬

## Summary
Lost IT? Found It! aims to streamline the process of reporting and recovering lost items at UTA. By providing essential features like user account management, item reporting, chat functionality, and notifications, the app seeks to alleviate the stress associated with losing personal belongings. The project was developed using established software engineering practices, ensuring a robust and maintainable application. 🚀
